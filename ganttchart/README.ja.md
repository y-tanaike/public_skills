# iGanttChart Skill — AIでガントチャート・工程表を作成

[English](README.md) | 日本語

**ganttchart** のSkillを使うと、プロジェクトの計画をタスク・日程・依存関係に整理し、**iGanttChart** で編集できるプレビューへのURLを生成できます。アプリIDは `ganttchart` です。`ganttchartai` は別のアプリです。

[tanaike.jpの使い方ガイド](https://tanaike.jp/app/ganttchart/skill/?hl=ja) · [iGanttChartを開く](https://ganttchart.tanaike.jp/) · [AI向けの手順](SKILL.md) · [全アプリのSkill](../README.ja.md)

## 作成できるもの

- 企画・デザイン・実装・確認に分けたWebサイト公開の工程表
- 締め切りや変更できない日程を含むイベント準備のスケジュール
- 親子タスクと依存関係で整理したプロジェクトの作業計画

利用前に日程と依存関係を確認してください。AIが提案する計画は修正が必要な場合があります。

## 会話で作りたいものを形にする

最初から仕様を完成させる必要はありません。「来月のWebサイト公開までの工程表を作りたい。足りない情報は質問して」と伝えて始められます。AIの質問に答え、「実装をもっと細かく分けて」「確認の期間を1週間長くして」などと会話で調整し、まとまったらアプリで開けるURLを返してもらいます。

### まずはSkillを追加せずに試す

作りたいものと一緒に、対象アプリの手順URLをプロンプトへ貼り付けます。リンク先のデータ仕様とURL生成ツールも参照するよう伝えてください。iGanttChartの場合は、次のように依頼できます。

> https://github.com/y-tanaike/public_skills/blob/main/ganttchart/SKILL.md の手順と、そこからリンクされているデータ仕様・URL生成ツールを参照してください。来月のWebサイト公開に向けたガントチャートを作りたいです。足りない情報は質問しながら、会話でタスクと日程を整理してください。工程名は日本語にして、まとまったらiGanttChartで開けるURLを返してください。

手順の本文を直接貼り付ける方法もあります。この方法ではSkillのインストールは不要です。[日本語](examples/sample.ja.json)・[英語](examples/sample.en.json)のサンプルも参照できます。

URL生成には、手順・参照ファイルの取得と、Pythonなどのコード実行に対応したAI環境を使ってください。URLを参照できない場合は、手順と参照先のファイルを直接渡します。URLを貼ることで閲覧機能や実行機能が追加されるわけではありません。

### 繰り返し使うならSkillを導入する

Skillに対応したAI環境に、対象アプリのディレクトリを `SKILL.md`・`scripts/`・`references/`・`examples/` ごと追加します。導入方法は環境によって異なります。導入して利用可能になった後は、次のように依頼できます。

> ganttchartのSkillを使って、来月のWebサイト公開までの計画を一緒に整理してください。足りない情報は質問して、iGanttChartで開けるURLを返してください。

毎回手順の全文やURLを貼り付ける手間を省き、作りたいものを会話で伝えられます。Skillが自動で選ばれない環境では、使うSkillの名前も明示してください。

## サンプルのURLを生成する

Python 3.10以降を使い、リポジトリのルートから実行します。

```bash
python3 ganttchart/scripts/create_url.py ganttchart/examples/sample.ja.json --name "Webサイト公開"
```

標準ライブラリのみでオフライン生成し、成功時はURLを1行で出力します。独自の内容を作成する場合は[データ仕様](references/content-format.md)を参照してください。日付は2001年1月1日UTCからの秒数で、依存関係にはタスクIDを指定します。

## よくある質問と制限

**URLを生成すればファイルが保存されますか？** いいえ。開くのは未保存の編集可能なプレビューです。予定を確認し、残したい場合はアプリで取り込んでください。新しいURLを生成しても、以前のリンクや保存済みファイルは更新されません。

**Google Driveは必要ですか？** URL生成にアカウントやAPIは不要です。アプリでの保存は別の操作です。既存のGoogle Drive上のファイルを共有するSkillではありません。

**内容は非公開ですか？** リンクを知っている人は内容を復元できます。圧縮は暗号化ではありません。共有したくない情報を含めないでください。8,000文字を超えるURLは生成を拒否するため、大きな計画は分割してください。

**どこまで検証されていますか？** 日英サンプルのオフラインでのURL生成・復号と、ローカルのFlutter受信処理を検証しています。公開中のUIでの描画・取り込み・保存を保証するものではありません。[検証記録](../apps.json)も参照してください。
