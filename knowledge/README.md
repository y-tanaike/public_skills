# public_skills の永続知識

このリポジトリを担当するすべてのAIが共有する知識です。作業の入口は [INDEX.md](INDEX.md)。
正式な仕様や手順が既存資料にある場合は移動・複製せず参照します。

- 保存するもの: 再発防止に有用な原因と対策、重要な制約、判断の根拠、検証条件、長期的な注意点。
- 保存しないもの: 会話全文、APIキー、生ログ、毎回の進捗、ソースの大量複製、根拠のない断定。
- 作成前に `rg` で既存資料と知識を検索し、同じ内容は既存ファイルを更新します。
- 種別は `architecture/`・`decisions/`・`lessons/`・`troubleshooting/` を必要になった時だけ作成します。
- 記録の最小項目は、確認日、状態（確認済み／仮説／失効／正式決定）、本文、根拠。大きな入力票は不要です。
- 実行履歴はbrainのruntimeへ記録し、知識本文には必要なTask ID・コミットだけを参照します。
- Gitの差分として確認できる状態にします。commit・push・公開はユーザーの依頼範囲に従います。

共通ルール: [brain/shared/policies/knowledge.md](../../brain/shared/policies/knowledge.md)。
